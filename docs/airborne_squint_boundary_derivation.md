# 机载条带大斜视：为什么没有统一的“RCMC最大角度”

本文使用实验002的局部平直、匀速、stop-go模型。所有公式中的r是点目标最近斜距，R(eta)是瞬时斜距；eta为慢时间s，fr与fa为真实距离频率和方位频率Hz。角度theta从正侧视向前视方向计。

## 几何和采样先于算法判据

固定r=30km、H=10km，地面横航迹距离y=sqrt(r^2-H^2)。波束轴经过场景中心时平台x=-r*tan(theta)，瞬时斜距r/cos(theta)。
theta增大时，地面场景不动，平台在更靠前的位置观测，R(0)增大。固定波束的两个角边缘给出每个点的完整照射入口和出口，而不是继续使用3.4s常数。

PRF必须覆盖**信号整个二维支撑**。给定距离频率fr和瞬时观测角psi，真实多普勒约为2v(f0+fr)sin(psi)/c。
因此只用2v*f0*sin(theta)/c判断是否超过PRF/2是不充分的：已知多普勒中心可先去中心，但角域带宽和B*sin(theta)形成的频谱斜置都要容纳。
采集窗包含完整脉冲、照射期间的距离走动和保护区；增加PRF还要核对接收窗与PRI。实验002保存sampling_geometry_checks.csv。

## 二维频谱与旧程度SRC的剩余项

忽略幅度因子，单点二维频谱可写为

S(fr,fa) ∝ exp(-j*pi*fr^2/Kr)
           * exp(-j*4*pi*r/c * q(fr,fa))
           * exp(-j*2*pi*fa*x_target/v)，

q=sqrt((f0+fr)^2-A^2)，A=c*fa/(2v)，D=sqrt(1-(A/f0)^2)。

对fr在0处展开：

q = f0*D + fr/D - A^2*fr^2/(2*f0^3*D^3)
    + A^2*fr^3/(2*f0^4*D^5) + O(fr^4)。

零阶项对应方位相位；一阶项对应距离徙动；二阶项是SRC；其余项属于更高阶距离、方位耦合。
正确RCMC消除一阶徙动，并不自动消除二阶参考误差和三阶以上项。不能把“做了斜视RCMC”理解为全部误差都消失。

本实验RD使用中心r_ref=30km的SRC。离中心点主要剩余二阶相位约为

delta_phi_2 = 2*pi*(r-r_ref)*A^2*fr^2/(c*f0^3*D^3)。

中心点二阶项被消去，仍有三阶项约为

delta_phi_3 = -2*pi*r*A^2*fr^3/(c*f0^4*D^5)。

随斜视增大，D变小，D^-3、D^-5项迅速增大。频带越宽、离参考点越远，近似越难满足。CS的参考调频率和变标也受到同类耦合和空间变化限制，具体残差须从完整处理与实测PSF判断。
实验输出src_phase_diagnostic.csv，用精确平方根与保留到二阶的频谱作差；只作机制核对，不代替成像判据。pi/4等经验相位误差线也不等价于本实验的PSLR/ISLR阈值。

## 中心精确相位的能力范围

精确中心R_ref(eta)的一维方位频谱可补中心参考的有限孔径相位。它没有包含fr这一维，不能把所有点的q(fr,fa)变成精确二维匹配。
用中心一维相位匹配后，仍可能出现中心尚好而边缘散焦，也可能因理想PSF旁瓣在某角度相互抵消而对小残差异常敏感。因此“通过”不一定随角度严格单调。
报告连续通过区间、首次失效及更高角度复现情况，比只报最后一次偶然通过更清楚。

## WK和BP的比较

经典omega-k保留q的平方根形式，Stolt映射处理频谱的弯曲。它不存在上述SRC二阶截断的同一误差项；本模型下的限制主要来自有限采样、频谱支撑处理和插值，以及模型失配。
BP对每个输出像素按实际平台轨迹计算R_pixel(eta)并相干累加，也没有将斜距历程截成二次式；它依然受到原始采样、距离插值、照射覆盖和实际传播模型的限制。
70deg仍通过时只能说明该模型和该判据下已验证至70deg。任何未测的更高角度均不能由本实验直接证明。

## 点扩散函数和度量坐标

大斜视二维点扩散函数一般倾斜。地面x轴、y轴的切片可能是两种带宽共同作用的结果，旁瓣不再都等于单一矩形孔径sinc的-13.26dB。
本实验在相同地面轴、同角度、同位置比较BP参照；ISLR用同一物理范围定义。切片采样会随高斜视倾斜后的窄主瓣自适应加密。
计算复数插值前去除已知空间载波，以避免“幅度看似正常但复数相位欠采样”造成错误展宽或异常锐化。
