## 数学与数值检查

1. 用 SymPy 独立检查变速度斜距的一至三阶导数关系、四阶驻相点反演以及五阶驻相相位的导数关系，全部通过。
2. 矩形线性调频脉冲频谱：对正、负调频率和 4 个频率点分别对比 Fresnel 公式与直接积分，绝对误差除以脉宽最大为 5.736e-16。
3. 圆轨道、球形地球、自转与参考几何斜视 45° 算例：14 阶局部斜距系数求值与直接轨道范数最大差为 1.164e-9 m；变速度导数与矢量径向速度最大差为 1.819e-12 m/s。
4. 固定参考等效速度的斜距模型与该理想轨道对比：最大斜距差 0.07025781 m，载频相位差最大 15.60845 rad。该量为原始传播相位差，未等价解释为成像性能结论。
5. 三个内部非退化驻相点，以三级等间距网格进行复 Simpson 求积；最后两级的相对变化最大约 3.36e-10。它是示例点数值收敛诊断，不是整个二维频带的严格误差证书。
6. 对应首阶驻相复谱相对误差约为 9.224e-4、5.798e-5、8.584e-4；驻相点求根很准确仍不使整个频谱成为精确结果。
