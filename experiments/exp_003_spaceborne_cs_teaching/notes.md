# 实验003：星载斜视SAR的CS图解教学实验

任务：使用既有频谱推导设计H1/H2/H3，独立生成和处理回波；保留每目标孔径内恒速、跨距离速度不同；以中文图文说明逐项解释公式及步骤。

## 运行

```matlab
addpath('D:/sar_project/experiments/exp_003_spaceborne_cs_teaching'); % 加入实验入口目录。
paths = run_generation(); % 只生成单点和九点原始回波，保存后返回路径。
summary = run_imaging(paths); % 只读已有回波，执行CS、评价、绘图及记录。
```

也可调用`run_all()`依次完成两步。新运行自动使用唯一编号，历史回波及结果不覆盖。代码面向MATLAB R2021b语法；实际安装和验证为R2022b。无需雷达或信号处理专用工具箱。

## 参数与方法

载频5.3GHz、脉宽37.1μs、带宽15.50829MHz、采样率18.962468MHz、PRF1700Hz；前两项使用ERS量级公开资料，带宽和采样率核对ISCE2固定版本`b7702cfbd571681a133ebc5c3b23a10c78d52706`。斜视5°、最近斜距850km、有效矩形孔径0.6s、2048×4096采样为教学设置，不冒充真实ERS观测或完整天线模型。

生成器采用完整等效双曲距离和有限LFM脉冲，逐目标使用Vr(r)。CS使用三个参考最近距离段，H1/H2局部冻结D和Km，H3按每个输出距离更新Vr，使用已知真实多普勒中心；全部段Dref=1，因此无需RCMC插值或拼接重采样。生成器不调用CS，处理器不读取targets/truth。轨道字段是圆轨道示意，不是回波实际欧氏轨迹。

- 正式结果：`results/exp_003_spaceborne_cs_teaching/run_20261104_223510_663/cs/`。
- 可提交记录：`records/run_20261104_223510_663/`，包括检查、完整生成/处理配置、采样与版本、总体结果及逐点CSV。

中心单点RCM跨度295.680m→0.0768m；校正后峰值偏差最大0.0430m。九点距离主瓣8.5311～8.5326m，方位主瓣5.0814～5.1017m，所有预设位置/宽度/旁瓣检查通过。九点最大距离插值峰值误差0.0471m；方位真值恰落网格，记录误差为0不能外推一般定位精度。中心单点CS峰值相对关闭RCMC/SRC联合处理对照约提高30.02dB，不分离两项补偿的各自贡献。

## 检查与试验历史

1. `run_20261104_221554_872`：第一轮，RCM检查通过而距离剖面失败；H3补了不必要的距离相关常相位，导致复数剖面插值失真。失败记录和本地结果保留。
2. `run_20261104_221709_944`：采用中心频率归一化的H3，同一输入重处理，单点与九点全部通过。
3. `run_20261104_223346_855`：重新生成含采样余量检查和固定来源版本的新数据，所有检查通过。
4. `run_20261104_223510_663`：独立读取第三轮保存的数据，自动输出完整复现配置；最终正式图文使用此运行，所有检查通过。

`tools/spaceborne_cs_teaching/verify_filters.py`核对配方、脉冲平移、距离空变残差及导数恒等式，并检查新增MATLAB逐行注释。误差网格在完整输出带和名义距离带内计算，但不是连续域严格上界。PDF由Markdown单源导出，检查正文、数学、图片和页边界，并查看全部最终页面。

## 结论边界

结论仅适用于已声明的等效模型、短矩形孔径、无噪声点目标、准确速度标定和已知多普勒中心。未验证实测星载原始数据、真实轨道误差、45°等大斜视、宽带、强速度空变或连续分布场景接缝；三距离速度变化仅约0.197m/s，不能据此宣称分段相对单参考有显著增益。
